iLyric Line Annotator

Blind reference annotation: no predictions are loaded or displayed. Files stay in this tab; nothing is uploaded. Work is autosaved in this browser.

Play with Space. Press Enter when the current line starts; it advances. Backspace undoes the last tap and rewinds 3 s. Edit a line by clicking its text; use the row buttons to insert, delete, or mark a line as not sung. Exact precision is not needed in this pass.

Select a line. Click the waveform to set its start, Shift-click to set its end. P plays the line, Space plays/pauses from the cursor, ↑/↓ change line, [/] nudge start, {/} nudge end (20 ms), U marks uncertain. Set the start at the first sung sound and the end at the last sung sound of the line.
