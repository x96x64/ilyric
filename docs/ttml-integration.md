# iLyric Bounded TTML Timing Integration

## Disposition and Starting Evidence

Retain the bounded experimental importer with qualifications. Standard namespace-qualified TTML paragraph/span timing now feeds the existing exact timeline and cluster-aware appearance path. Explicit paragraph ends bound focus; no timed fragment is independently shaped. Version 3 selects TTML without changing versions 1 or 2. Production `ilyric`, typography, appearance primitives, focus motion, full-screen geometry, audio conversion, and the writer remain unchanged. This is local interchange support, not a complete TTML processor or native Music fidelity result.

The empirical reference remains reported iPhone 16/iOS 27.0.1, exact build **Unknown**, Default Display Zoom, Text Size 4/7 counting the smallest as 1/7, Bold Text/Reduce Motion/Reduce Transparency/Increase Contrast off, Light appearance, and English system/Music languages. No new physical measurement or private Apple lyric format was inferred.

## Specification and Subset Decision

The [subset contract and invocations](ttml-subset.md) were written before implementation. Research used the [W3C TTML2 Recommendation of 8 November 2018](https://www.w3.org/TR/2018/REC-ttml2-20181108/), the [Timed Text Toolkit timing verifier](https://github.com/skynav/ttt/blob/master/ttt-ttv/src/main/java/com/skynav/ttv/verifier/ttml/TTML1TimingVerifier.java), and [AMLL's current TTML parser](https://github.com/amll-dev/applemusic-like-lyrics/blob/main/packages/ttml/src/parser.ts). The verifier separates timing coordinates, durations, and containers. AMLL's provider-oriented parser has extensions, text normalization, fallback timing, and millisecond rounding that are outside this contract. No implementation code or dependency was imported.

The implemented subset requires `tt/body/div/p`, standard namespaces, preserved whitespace, media time, and parallel containment. Paragraphs use text/explicit `br`, or fully timed direct spans/`br`. A span may contain an explicit break or cross automatic wrapping. Nested spans, mixed timed/untimed paragraph content, styling, regions, ruby, embedded media, sequential containers, profiles, and provider extensions are rejected. Bounded `xml:id`/`xml:lang` are informational; they do not implement language selection, translation, or styling.

Clock expressions and decimal `h`, `m`, `s`, and `ms` offsets use exact rational arithmetic through six fractional digits. Both begin and end are parent-relative coordinates; duration is relative to the element's start. Containers inherit omitted bounds, but paragraphs/spans require explicit begin and exactly one end or duration. Zero/negative intervals, overlaps, ordering violations, unsupported units, missing precision, conflicting end/duration, and out-of-parent/audio intervals are refused. TTML permits more cases, including zero duration and minimum resolution when both end/duration exist; this importer deliberately rejects those cases rather than approximating them.

## XML Safety and Text Preservation

Foundation XML parsing operates on bounded UTF-8 XML 1.0 data with namespace processing, external resolution disabled, policy `never`, and a refusing external-resource delegate. Forbidden XML controls, including NULs, are rejected before automatic XML encoding recognition. A controlled check established that the initial implementation accepted UTF-16 data with an unused internal DTD before reaching audio preparation. The corrected guard prevents that encoding/declaration bypass; internal entity expansion or enabled external resolution was not established. Document-type/entity declaration tokens are rejected before parsing, even inside comments/CDATA. Processing instructions, alternative encodings, external resources, and unknown elements/attributes fail. Unused namespace declarations are inert and never fetched. Standard character references and predefined XML entities are decoded normally. No external lookup or rendering-time network access occurs.

The limits are 64 KiB, depth 6, 1024 elements, 64 paragraph/gap intervals, fewer than 500 UTF-16 units and at most four supplied/rendered lines per paragraph, 128 spans per paragraph, 512 per document, and ten minutes. A bounded SAX-built content tree aborts on violations; it retains neither an unbounded recursion nor a resource resolver. These controls establish the tested refusal policy, not a comprehensive XML security certification.

Root `xml:space="preserve"` is mandatory; descendants may repeat it but cannot request collapsing. XML 1.0 line-ending and attribute normalization remains distinct from Unicode normalization. Spaces, punctuation, combining sequences, variation selectors, and joiners are retained. Text-node tabs/line breaks are rejected; `br` supplies the supported line structure. Formatting whitespace outside paragraphs is noncontent. Timed paragraphs cannot silently discard inter-span spaces: those spaces must belong to a supplied timed span. Comments have no text effect; supported CDATA contributes exact content.

UTF-16 ranges refer to the complete decoded paragraph. Extended grapheme validation occurs before rendering; whole-paragraph Core Text separately verifies visual cluster boundaries. Existing split-cluster, timed right-to-left, and color-glyph restrictions remain in force, including disabled preparation. Unicode stress inputs preserve original sequences even where progressive raster support is rejected. The local font remains provenance, not identified native iPhone typography.

## Timeline and Configuration Integration

`LyricEntry.intervalEnd` is optional. LRC/enhanced-LRC retain `nil` and their existing next-event/final-hold policies. TTML supplies exact ends, including empty intervals. Local focus excludes the end boundary; compilation adds a no-focus event only when no following event begins there. Adjacent intervals transfer focus directly without a one-frame gap. Offset handling shifts paragraph and span boundaries together. Audio length and less-than-one-frame silence padding are unchanged.

Span completion cannot change focus. Before a span its support is dim; supplied intervals drive inherited script-aware visualization; completed support persists until paragraph departure. That persistence is a Lyrics reconstruction choice, not general TTML subtitle-removal semantics. Untimed paragraphs stay line-level. Disabled highlighting retains the supplied data and explicit end semantics while using static appearance. Latin/Japanese appearance parameters and whole-paragraph layout are unchanged.

The direct experimental selector accepts `--format ttml`. Version 3 adds TTML to the existing explicit format enum; version 2 still rejects it, and version 1 still rejects format/highlighting fields. Strict unknown-field, path, metadata, artwork, visibility, output, and preparation rules remain intact. No finalized project schema, format guessing, provider integration, or production CLI redesign was introduced.

## Privacy, Limitations, and Next Gate

Private references and diagnostics remain ignored. V01–V03 and V09/V10 hashes are unchanged; existing Latin measurements reproduce their baseline, and twenty archived Japanese appearance/coverage/state records remain byte-identical. These are nonregression checks, not new physical fitting. Historical reports/profiles and original-history backups remain preserved. Public additions contain original fixtures, code, tests, and sanitized evidence only.

Go for this documented local TTML subset; no-go for universal TTML/provider compatibility or native Music fidelity. Important limits include explicit end requirements, fully timed span coverage, preserved-whitespace-only import, nonoverlapping intervals, no styling or provider extensions, and existing directional/color-glyph exclusions. The static background, original control placeholders, native-to-portrait `contain`, motion approximation, and synthetic timing visualization retain their prior qualifications.

The next narrow priority should be user-supplied Lyrics Translation correspondence: explicit original-to-translated paragraph mapping and synchronized line-level focus with independent translated typography/spacing. Fine-grained translation timing must not be inherited from original spans. Automatic translation, external retrieval, lawful acquisition, dynamic materials, SF Symbols licensing/export rights, generalized customization, and `adapt` remain separate deferred gates.
